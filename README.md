# AI-Powered Sleep Apnea Detection System

## Overview
An AI-powered web application that analyzes health-related parameters to identify possible signs of sleep apnea. It also provides live monitoring of heart rate (BPM) and blood oxygen saturation (SpO₂).

## Features
- User registration and login
- Machine learning-based sleep apnea prediction
- Live BPM and SpO₂ monitoring dashboard
- Real-time sensor data integration
- Status alerts for abnormal readings
- Visual charts using Chart.js

## Technologies Used
- Python
- Flask
- Machine Learning – Random Forest
- Scikit-learn, Pandas, Joblib
- HTML, CSS, JavaScript
- Chart.js
- SQLite
- ESP32 and MAX30100

## Installation and Setup

1. Clone the repository:
   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

2. Open the project directory:
   ```bash
   cd Sleep-Apnea-Detection
   ```

3. Create and activate a virtual environment:
   ```bash
   python -m venv .venv
   ```

4. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```

5. Run the application:
   ```bash
   python app.py
   ```

6. Open `http://127.0.0.1:5000` in your browser.
